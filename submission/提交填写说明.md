Long description（以下四段可复制；提交前请自己读懂并确认）：

Learning HTML is my classroom practice website for the Web Technologies course. It brings together a homepage, a quote collection, a project notebook, an About page and a playground. It is intended for classmates and anyone interested in exploring small examples of web development.

The quote collection contains twenty classical Chinese quotations with English renderings, attribution and source links. A random quote appears at the top of the page, and a button selects another without repeating the current one. The project notebook compares five possible websites and the audiences they could serve; these are working ideas rather than a final personal-project choice.

The playground includes an Almost Machine whose progress reaches 99 percent before returning to zero, and a number-guessing game with six tries, higher-or-lower hints and a restart option. The activities support keyboard and pointer input. The layout adapts to different screen widths, and the progress animation respects the reduced-motion setting.

I developed this learning site with Codex assistance using HTML, CSS and plain JavaScript. Shared navigation and footer fragments avoid repeating the same markup on every page. Quotation sources are named, and the English renderings are identified as prepared for this site with AI assistance. The local version has been checked for navigation, resource loading, responsive layout and game behaviour; I still need to review and understand the code before presenting it as my work.
